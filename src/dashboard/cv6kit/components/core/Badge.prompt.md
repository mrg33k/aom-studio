Tiny count or status pill beside section headers and room rows.

```jsx
<Badge tone="weak">4</Badge>      {/* Catch up · 4 */}
<Badge tone="solid">3</Badge>     {/* unread */}
<Badge tone="chip">28</Badge>     {/* mission count */}
```

Min 20px square, grows with digits. `weak` is the most common (accent text on accent-weak).
