Conversation messages. Agents are labelled and left-aligned with an avatar chip; the user's own messages are right-aligned accent bubbles with a tucked bottom-right corner. Inline `code` uses Space Mono on a chip fill.

```jsx
<MessageBubble from="agent" author="Elon" initials="EL" time="7:20">
  Repo not found. Want me to retry?
</MessageBubble>
<MessageBubble from="me">Retry — but pin the framing first.</MessageBubble>
```
