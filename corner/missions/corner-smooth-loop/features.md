## Feel checks (judge by hand)

- Sign-in first paint: web cold load -> splash timing + time to room list (`/`); native cold launch -> time to rail paint (both, stopwatch).
- Streaming reply cadence: word-by-word flow + cursor in `/room/r6` (web) and Chat (native); no chunk jumps or frozen-then-dump.
- Thinking -> reply transition: spring stiffness of the turn indicator appearing/clearing in `/room/r6` vs Chat.
- Keyboard avoidance: room composer with keyboard up on iPhone SE web (`/room/r6`) and native Chat; field never hides behind the keyboard, send stays tappable.
- Pull-to-refresh: native Home rail, Chat (`refreshable`), Tracker, Organize folder, Email; web has none (note as gap if it matters).
- Haptics: native card-tap light impact (single, not double), send spring, checklist toggles; web send-button scale only.
- Scroll restore: FAB appears only when scrolled up on new arrival; tap returns to bottom and clears, both platforms.
- Drawer/sheet physics: web drawer spring + scrim fade (`/ -> menu`), files sheet settle, palette slide; native settings/files/decision sheets detents + drag indicator.
- Page transitions: Home <-> Room slide direction and duration (web `App.tsx` animation map); native push/replace has no black flash on rapid notification taps.
- Theme switch: instant re-ground with no flash or tree reset; native theme change must not kill open-chat stream state.
- Splash vs skeleton handoff: web splash 1200ms must not double-flash into skeletons on fast loads.
- Voice: native dictation start/stop latency + "Listening… tap to stop"; web mic is a placeholder (no feel to judge).
- Long-thread growth: 50+ message room, scroll smoothness and animation cutoff (web disables per-row animation past 10 rows).
