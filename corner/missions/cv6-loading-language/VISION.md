# CV6 Loading Language - Mission Vision

**Mission path:** `corner:cv6-loading-language`

## North Star

Corner CV6 has one branded, honest loading language: calm, token-native, wordmark-first, and brief. It should tell the user the app is alive and almost here, then disappear as soon as the real state is known.

## Principles

- One shared primitive for fullscreen and content-area loading.
- Hanken Grotesk wordmark first: `Corner.`
- No generic spinners, bouncing dots, or one-off per-screen copy.
- Token-only color and spacing so dark, light, and glass themes all work.
- Loading only appears while something is genuinely loading.
- Empty, error, offline, and unconfigured states stay explicit and honest.
- Long loads trip a watchdog and stop pretending everything is normal.
- Mobile fullscreen loading respects safe-area insets.
