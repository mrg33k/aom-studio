# Room Checklists — Mission Vision

**Mission path:** `corner:room-checklists`
**Started:** 2026-07-21

## What this mission is

A small user-owned checklist notebook inside every Corner room, available directly
from the second composer row. It is separate from the agent's work plan: the user can
keep notes, create multiple named lists, finish or delete items, and deliberately send
an item to the room agent when it is ready to become work.

## North star

Every room keeps the user's loose ends close enough to capture instantly and structured
enough to turn into agent work with one intentional press.

## Product pillars

1. **Per-room and durable.** Lists belong to one room and survive navigation and reloads.
2. **User-controlled.** Nothing becomes agent work until the user presses Play.
3. **Quietly capable.** Multiple named accordion lists support notes without taking over chat.
4. **Portable with consent.** Sharing always confirms Copy (keep both) versus Move.

## Non-goals

- Replacing the agent work plan or Goal Thread.
- Automatically sending, prioritizing, or completing user notes.
- Turning the composer into a full project-management tool.
