# Clip Packages — Vision

**Mission path:** `aom-site:clip-packages`

Put the clipping service on the aheadofmarket.com homepage so people can find it and see it working.
Each client gets a small branded package (their colors, type, logo and ChatGPT brand board) with three finished
clips, so a prospect sees the "package" they would get. Under the shelf, one offer: send a link, get three free clips.

Decided with Patrik 2026-09-28:
- A solid homepage section, not a footer link. Real clips playing, not a description of the service.
- One package per client, three clips each: Ambition, Wolfpack, Oak Street, Kody Romero, then every new client.
- Package cards, tap to open. Each package is styled in that client's brand.
- Call to action: "Send a link, get 3 free clips" (same gift as the outbound email).
