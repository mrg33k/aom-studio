# Corner AirPods Mode — Research

- Gemini Live should use authenticated ephemeral tokens for client-to-server sessions.
- Paid live sessions must be opened only after activation and closed after inactivity;
  armed wake detection and attention prompts remain local.
- iOS background capture requires a native audio session, the audio background mode,
  explicit microphone consent, and conspicuous recording state.
- A Capacitor shell preserves the existing React/CV6 surface while allowing Swift
  plugins for audio, wake detection, remote controls, and secure storage.
- Picovoice Porcupine is the selected replaceable wake adapter for web and iOS; licensing
  and production key handling remain release gates.
