# Integrations — Mission Vision

**Mission path:** `corner:integrations`

## What this mission is

The durable source of truth for Corner's external-service, deployment, and environment integrations.

## North star

Every integration has one unambiguous owner, environment, and verification path.

## Pillars

- Production and staging targets are named accurately everywhere.
- Production is the default release destination unless a user explicitly requests staging.
- Deployment automation cannot silently promote staging language or behavior to production.
- Release verification checks the user-facing canonical URL.
