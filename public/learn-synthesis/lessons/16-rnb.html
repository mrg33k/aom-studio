Module 16 · Build lab

Build an RNB sound

RNB is about warm, soulful keys layered over a soft bottom end. You'll stack an FM2 e-piano with a sine sub and a wavetable pad. The result feels luxurious without any aggression.

The idea

Soft layers make the magic

Imagine three singers stacked on top of each other, each singing a different note at a different speed: a warm horn playing the melody, a deep hum underneath, and a wash of pads floating around them. That is RNB on the MPC.

FM2 (the top layer) is a synth oscillator that rings like a bell or an electric piano. Add a warm sine sub underneath for depth without harshness. Top it all with a wavetable pad that evolves slowly on its own. Mellow filters keep everything smooth. No bright edges, no sharp attacks. Feel over aggression.

The secret: velocity. Softer hits get softer envelopes, so playing with touch shapes the whole thing.

On the MPC · Samples/Oscs tab

The finished RNB patch: three layers working as one

Each layer has its own oscillator type. Layer 1 is FM2 (the warm keys). Layer 2 is Warm Sine (the sub). Layer 3 is Wavetable (the pad). All three pour through the same filters, controlled by the same amp and filter envelopes. When you hit a key, all three play, and the whole patch breathes as one voice.

Build it with me · your first RNB patch

Five steps to warm RNB keys

  1. Make a keygroup trackNew track, set its type to Keygroup. You are now in the synth builder.
  2. Layer 1: set FM2, tune it warmSamples/Oscs tab. Switch Layer 1 to Oscillator, choose FM2. Set Level to 85. Turn FM Decay down a little so the tone stays warm and not metallic.
  3. Layer 2: add Warm Sine subEnable Layer 2. Set it to Oscillator, choose Warm Sine. Set Level to 32, Semi down to minus 12 (one octave lower). This is your foundation.
  4. Layer 3: add a Wavetable padEnable Layer 3. Set it to Oscillator, choose Wavetable. Set Level to 24. Use the Mod Matrix to wire a slow LFO to Wavetable Position so it evolves.
  5. Filter and envelope for the swellOn the Filters tab, set a gentle low-pass. Cutoff around 3000 Hz. On the Amp envelope, raise Attack to 120ms and Release to 1.5 seconds. Now it swells like a pad.
  6. Velocity to everythingOn the Envelopes tab, set Velocity To Attack and Velocity To Level on the Amp. Now when you play soft, it sounds softer. Play a chord and let it breathe.
