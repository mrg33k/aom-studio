Module 15 · Build lab

Build horns with bite

A trumpet player takes a breath, attacks hard, and the note gets bright and punchy. You'll build exactly that with two tools: a sine/saw wave and a filter that opens when you hit harder. By the end you will hear how velocity shapes a brass sound, and you will build a patch that people mistake for a real horn.

The idea

A bright punch from a fast start

Imagine a trumpet player. At the moment they blow hard, the horn gets brighter, more cutting, more present. That brightness is what makes a horn a horn.

We build that two ways. One: use a sampled brass multisample, where harder hits play a harder-recorded horn sample. Two: use a simple shape like Saw or Square, add a band-pass filter (which lets only the middle frequencies through), and dial in a fast attack. The trick is a tiny pitch blip on the attack (what we call a pitch envelope). That blip makes it sound like a player is attacking, not just turning on an oscillator.

Then you wire velocity to the filter. Hit harder, filter opens more, the horn gets brighter. That is the whole secret.

Build it with me · make a velocity-dynamic horn

Six steps to your own horns patch

  1. Make a keygroup track and set Poly to MonoNew track, type Keygroup. In the Global tab, set Poly to Mono so only one note plays at a time, just like a horn player.
  2. Set Layer 1 to Oscillator, choose Saw/SquareOn the Samples/Oscs tab, switch Layer 1 from Sample to Oscillator, then pick Saw/Square from the list.
  3. Add a band-pass filterOn the Filters tab, set Filter 1 to Band-pass. This cuts the low and high ends, leaving the brass in the middle. Set Cutoff around 1200 Hz, Resonance around 20.
  4. Wire velocity to the filterOn the Filters tab, turn up Velocity Sensitivity on Filter 1 to around 60. Now hitting harder opens the cutoff. The horn gets brighter.
  5. Make a fast attackOn the Amp envelope, set Attack to about 0.08 seconds (fast like a tongue attack). Set Decay to 0.3 s, Sustain to 100 percent, Release to 0.4 s. This keeps the note stable after the attack.
  6. Add a pitch envelope blip (the secret sauce)On the Pitch envelope, set Attack to 0.05 s with a high Depth value (around 30 semitones). Set Decay very short (0.1 s), Sustain to zero. This drops the pitch fast after the attack. That blip is what makes it sound like a horn player, not just an oscillator.
