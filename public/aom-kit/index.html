Precision HTML built for the html.to.design Figma plugin. Import each page URL and every section becomes an editable Figma frame — real text, real tokens, real layers. Tweak components, copy the patterns, and build from the brand lock.

++
How to Import
  1. 01.Open Figma. Install the html.to.design plugin from the Figma Community if you haven't already.
  2. 02.Run the plugin. Choose "Import from URL" (not paste HTML).
  3. 03.Paste each URL below, one at a time. Each page becomes its own Figma page.
  4. 04.Import order: tokens.html first (the reference), then components.html, then home.html, then shoot.html. This keeps the layer hierarchy clean.
  5. 05.Class names are Figma layer names. "hero", "module-col", "math-table" — the DOM is already named like layers.
